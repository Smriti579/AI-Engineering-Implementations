# Object-Oriented Java

Java implementations exploring core object-oriented and language-level programming concepts.

This section focuses on interfaces, functional programming features, package organization, and exception handling.

---

## Topics Covered

- Java packages
- Interfaces
- Functional interfaces
- Lambda expressions
- Exception handling

---

## Concepts Demonstrated

### Interfaces

Implementing and working with Java interfaces to define common behaviour and structure across classes.

### Functional Interfaces

Working with functional interfaces as part of Java's functional programming capabilities.

### Lambda Expressions

Using lambda expressions to implement functional behaviour with concise syntax.

### Exception Handling

Handling runtime and program-level exceptions using Java's exception-handling mechanisms.

### Packages

Organizing Java classes using packages and understanding package-based code structure.

## Purpose

These implementations provide hands-on practice with important Java language features used in structured and maintainable software development.
